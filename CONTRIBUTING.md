# Contributing to Riverbraid

This guide defines a bounded public contribution posture for Riverbraid.

It does not create a staffed support obligation, guaranteed review timeline, employment relationship, legal agreement, certification process, or production readiness claim.

## Current contribution posture

Riverbraid is an open source deterministic integrity floor for AI governance.

The preferred public starting point is:

```text
Riverbraid-Evaluation-Kit
```

Contributions should preserve Riverbraid's public boundaries:

- no claim expansion
- no certification language
- no production readiness claims
- no external audit claims
- no legal approval claims
- no absolute security claims
- no adoption claims without evidence

## Before contributing

Review:

1. `Riverbraid-Evaluation-Kit`
2. `Riverbraid-Documentation/docs/SYSTEM_MAP.md`
3. `Riverbraid-Documentation/docs/REPOSITORY_LIFECYCLE_INDEX.md`
4. the target repository README

## Contribution types

Useful contributions may include:

- documentation clarification
- typo correction
- verification reproduction notes
- issue reports
- boundary clarification
- metadata consistency improvements
- test vector discussion
- public packaging improvements

## Pull request expectations

Pull requests should state:

- what changed
- why it changed
- files changed
- whether code changed
- whether workflow changed
- whether registry changed
- whether protocol semantics changed
- what claims are not being made

## Claim boundary

Do not submit changes that imply certification, legal approval, production readiness, external audit, complete AI safety, absolute security, adoption, or absence of defects unless a separate public evidence surface supports that claim.

## Response boundary

Submitting an issue or pull request does not guarantee review, acceptance, merge, maintenance, or response within a specific time.

## License boundary

Only contribute content you have the right to contribute.

## Maintenance

Update this guide if Riverbraid's governance surface, review capacity, or contribution process changes.
