# Code of Conduct

This code of conduct defines basic expectations for public Riverbraid collaboration spaces.

It is a public participation boundary only. It does not create legal advice, legal enforcement, guaranteed moderation, staffed support, certification, or external review.

## Expected behavior

Participants are expected to:

- communicate clearly and respectfully
- stay within the scope of the repository or issue
- avoid harassment, threats, personal attacks, and targeted abuse
- avoid posting private information, secrets, credentials, or sensitive exploit material
- distinguish evidence from speculation
- preserve Riverbraid's claim boundaries

## Unacceptable behavior

Unacceptable behavior includes:

- harassment or discriminatory abuse
- threats or intimidation
- publishing private information without consent
- spam or disruptive off-topic activity
- knowingly misrepresenting Riverbraid's verification status, safety status, certification status, or adoption status
- submitting malicious code or intentionally misleading reports

## Scope

This code applies to public Riverbraid repositories, issues, pull requests, discussions, documentation surfaces, and related public collaboration spaces controlled by the Riverbraid account.

## Enforcement boundary

Riverbraid may moderate or close issues, pull requests, comments, or discussions that violate these expectations.

No guaranteed response time, appeal process, moderation staffing level, legal process, or enforcement outcome is promised by this document.

## Reporting

Use the relevant GitHub repository issue or discussion surface when a concern can be shared publicly.

Do not publish private information, credentials, secrets, or sensitive exploit details in public issues.

## Claim boundary

This code of conduct does not claim legal approval, third party governance review, external audit, certification, or formal institutional moderation.

## Maintenance

Update this document if Riverbraid's public participation model changes.
